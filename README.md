## What I work on

- **Distributed backends** — event-driven microservices in Go and Node/NestJS, Kafka pipelines, idempotent and retry-safe APIs, Postgres and MongoDB schema design and indexing.
- **Platform and delivery** — Docker and Kubernetes on AWS and GCP, Terraform, GitHub Actions / GitLab CI, observability with OpenTelemetry and Grafana.
- **AI engineering** — LLM-backed services with structured outputs, retrieval over pgvector, and eval harnesses so changes can be shipped with a regression gate rather than a hunch.
- **Frontend when it matters** — React, Next.js and Angular for the parts of a product that users actually touch.
